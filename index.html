Un suivi privé des candidatures.
Un accès Gmail en lecture seule.

Stage Radar Mail Reader aide son propriétaire à retrouver les confirmations de candidature, les refus, les demandes complémentaires et les invitations à un entretien dans ses propres boîtes Gmail autorisées.

Ces pages présentent l’application. Elles ne donnent accès à aucune boîte mail, candidature, conversation ni interface privée. Elles ne proposent pas d’inscription publique.

Pourquoi connecter Gmail ?

Le suivi doit pouvoir distinguer les emails liés à une candidature des autres messages, identifier l’entreprise et le poste, puis rattacher les réponses à la bonne offre. Les comptes sont connectés individuellement par leur propriétaire avec OAuth Google.

L’autorisation demandée est https://www.googleapis.com/auth/gmail.readonly. Elle permet de lire les messages et leurs métadonnées, sans les envoyer, les supprimer, les déplacer ni les marquer comme lus.

Comment les données sont utilisées

  1. Les emails des comptes autorisés sont récupérés en lecture seule pour déterminer lesquels concernent le suivi de candidatures.
  2. Le texte et les métadonnées nécessaires sont analysés, notamment via l’API Xiaomi MiMo, pour proposer une classification et une association à une offre.
  3. Les résultats et l’historique utile sont enregistrés dans une base privée et consultables uniquement dans l’application privée du propriétaire.

Les jetons OAuth Google ne sont jamais transmis au modèle d’IA. L’application n’entraîne pas de modèle sur les emails. Ses propres alertes utilisent un canal d’envoi distinct de l’autorisation Gmail en lecture seule.

Le propriétaire garde le contrôle

L’accès peut être révoqué dans les connexions du compte Google. L’analyse automatique peut comporter des erreurs ; les décisions importantes doivent être vérifiées dans les messages sources.

Les usages, les destinataires techniques, la conservation et la suppression des données sont détaillés dans la politique de confidentialité.
